4. TAMPERMONKEY SPONSORED GUIDE

  1. Install the official free Tampermonkey browser extension in your Web Browser.
  2. Open the Tampermonkey icon in your browser extension toolbar and select Create a new script...
  3. Select and copy the entire text block from Section 5 below.
  4. Paste the copied script into your Tampermonkey editor canvas (replacing default placeholder template code).
  5. Press Ctrl + S or click File -> Save in Tampermonkey.
  6. Open repuls.io and your newly configured custom crosshair will render on screen!
